# RED DYNASTY — Manchester United Fan Website

This is a complete static fan website designed for GitHub Pages.

## Files
- index.html — page structure
- styles.css — premium visual design and animations
- script.js — fixtures/table data, scroll effects and interactions
- assets/favicon.svg — custom fan-site favicon

## Important
This is an UNOFFICIAL fan-made project and is not affiliated with Manchester United Football Club.

The fixture/result snapshot was prepared from current public fixture information. For a production client website, connect a licensed football-data provider/API so scores, fixtures and tables update automatically.
